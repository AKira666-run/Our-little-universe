📁 这个文件夹用来存放你们的真实照片

1. 把照片(jpg / png 都可以,建议单张 2MB 以内)放进本文件夹
2. 打开 config.js,把对应条目的路径改成你的文件名
   例如:coverImage: "public/images/cover.jpg"
3. 各占位图对应关系:
   cover.svg            → 首页封面(建议横版)
   avatar-me.svg        → 你的头像(建议正方形)
   avatar-partner.svg   → TA 的头像(建议正方形)
   memory-01~08.svg     → 「我们的故事」时间轴照片
   gallery/ 里的图片    → 「回忆相册」照片(横竖不限,竖版更好看)

替换后删除不用的 .svg 占位图即可。
